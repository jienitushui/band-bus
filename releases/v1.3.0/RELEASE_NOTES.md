## 本版本内容

### 功能

- 全国已开通城市切换与跨端城市同步
- 附近站点、线路/站点搜索、公交换乘
- 实时公交候车、关注项同步到手表
- 线路详情换向、单向线路提示
- 手机「定位中继」：锁屏后仍可向手表回传 GPS

### 体验与稳定性

- 请求链路与定位缓存优化，首屏更快
- 首页有定位缓存时后台校正会真正刷新坐标，避免附近站点“刷新了却不变”
- 互联错误（如 `fingerprint verify failed`）改为中文说明，并避免失败通知刷屏

### 文档

- 仓库根目录完善开源 `README.md`
- 补充互联排障说明（`腕上公交互联排障.md`）

## 系统要求

- **手机**：Android 7.0+，已安装「小米穿戴」并与手表绑定
- **手表**：支持 Vela 快应用的小米手环 / REDMI Watch 等

## 已知注意

- 公交数据来自第三方接口，以当地开通情况为准；默认城市为泉州
- 首次使用务必按 `INSTALL.md` 顺序安装并做互联自检 / 穿戴授权
- 若曾装过不同签名的旧包，请先两端卸载再装本 release，避免指纹校验失败
