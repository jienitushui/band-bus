# 腕上公交 · 手表端

本目录为 **Vela 快应用**工程（包名 `uno.keyin.bus`）。

完整的开源说明、双端编译、安装与互联排障请查看仓库根目录：

→ [../../README.md](../README.md)

## 本目录速查

```bash
npm install
npm run build      # 生成 dist/*.rpk（debug 证书）
npm run release    # release 出包
npm start          # 本地预览 / 调试服务
```

- 签名与手机 APK 对齐：见 [`sign/README.txt`](sign/README.txt)
- 互联故障：见仓库根目录 [`腕上公交互联排障.md`](../腕上公交互联排障.md)
